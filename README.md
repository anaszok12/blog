# anaszok blog

Personal blog about BIM and Revit, built with [Astro](https://astro.build) and Tailwind CSS.

Live at https://anaszok12.github.io/blog/

## Writing posts
Use [Pages CMS](https://app.pagescms.org), or add a Markdown file to `src/content/blog/`.
Every push to `main` rebuilds and publishes the site automatically.
